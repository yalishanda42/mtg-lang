# MTG-Lang v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A glossary-driven, language-independent notation for Magic card text, with tools (fetch, validate, render, back-translation bundle) and all ≈596 `trk` + `fra` main-set cards translated and reviewed.

**Architecture:** Python package `mtglang`. All closed vocabulary (symbols, keyword nicknames, structural marks) lives in YAML glossary files, not in code. A hand-written longest-match tokenizer turns a line into tokens using the glossary. A small Lark (Earley) grammar checks the structure of each ability line. Card files (`cards/<set>/<slug>.mtgl`) are split into header and ability lines by Python. The validator compares them with a cached Scryfall snapshot. The renderer produces a static HTML gallery and an ASCII export.

**Tech Stack:** Python 3.12, uv, lark, pyyaml, jinja2, pytest. Stdlib `urllib` for HTTP (no requests).

**Spec:** `docs/superpowers/specs/2026-11-23-mtg-lang-design.md`

## Global Constraints

- Scope: main sets `trk` (Star Trek) and `fra` (Reality Fracture) only, Scryfall query `e:<code>` with `unique=cards`. Excluded: `trc`, `frc`, token sets, Alchemy, art series, promos.
- Scryfall: send `User-Agent: mtg-lang/0.1` and `Accept: application/json`. Sleep ≥100 ms between requests. Cache to `data/`, and only `mtglang fetch` hits the network.
- Token rule: every card-text token is a glossary symbol, number/variable (`X Y Z`), mana symbol `{…}`, fixed punctuation, or a delimited proper name / named effect.
- Closed-vocabulary glyphs and ASCII aliases must not contain a run of **3 or more ASCII letters**. Word-like text (`[A-Za-z]{3,}`) outside name/effect delimiters is an error.
- Fixed (reserved) punctuation, never usable inside glossary glyphs/aliases: `[ ] ( ) { } , / + - —` and the letters `X`, `Y`, `Z` as standalone glyphs. A line whose first non-space char is `#` is a comment.
- Strict fidelity: identical normalized Oracle lines must map to identical notation (validator **error**).
- Named effects target: < 5% of ability lines (validator **warning** above it).
- Every symbol has an ASCII alias. The parser accepts glyph and alias interchangeably.
- Each card file has exactly one ability line per normalized Oracle line, per face, in order.
- Git: commit after each task. Author is the local repo config ("AI"). Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Oracle lines made only of reminder text** (e.g. `({T}: Add {G}.)`) must be dropped from alignment, and a keyword line like `Flying (reminder…)` must normalize to `Flying`. Test in Task 3.
2. **Proper names with commas, apostrophes, digits** (`Dal R'El, Augment Orphan`, `70,000 Light-Years from Home`) must tokenize as one name and slug predictably. Tests in Tasks 1 and 5.
3. **Card files with CRLF line endings, trailing spaces, or no final newline** must parse identically to clean files. Test in Task 6.
4. **Unknown glyph or English word in a card line** must produce an `Issue` with file, line and column, never a crash or traceback. Tests in Tasks 5 and 7.
5. **Face-count mismatch** (file has 1 face, Scryfall has 2) and **vanilla cards with no Oracle text** must give a clear error and a clean pass respectively. Tests in Task 7.

### Task 5: Glossary model, self-checks, tokenizer

**Files:**
- Create: `mtglang/glossary.py`, `mtglang/tokenizer.py`, the fixture files listed above
- Test: `tests/test_glossary.py`, `tests/test_tokenizer.py`

**Interfaces:**
- Consumes: `Issue`.
- Produces:
  - `ROLES: tuple[str, ...]` (the 13 roles listed in Task 4 Step 7). `GRAMMAR_ROLES = ("implies","cost_sep","label_sep","mode_bullet","threshold_sep","chapter")`.
  - `Symbol(glyph: str, ascii: str, cls: str, labels: dict[str,str], role: str | None = None, oracle: str | None = None, definition: str | None = None)`
  - `Name(key: str, cls: str, labels: dict[str,str])`, `NamedEffect(key: str, card: str, labels: dict[str,str])`
  - `Glossary(symbols: list[Symbol], names: dict[str, Name], effects: dict[str, NamedEffect])` with `lookup: dict[str, Symbol]` (glyph and ascii → Symbol), `role(r: str) -> Symbol`, and `label(sym_or_name, lang="en") -> str` (falls back to `en`, then to key/glyph).
  - `load_glossary(dir: Path) -> Glossary` (reads `symbols.yaml`, `names.yaml`, `named_effects.yaml`; YAML field `class` → `cls`).
  - `check_glossary(g: Glossary) -> list[Issue]` with codes:
    - `G-DUP`: a glyph/alias string is used by two symbols. The same symbol having glyph == ascii is OK.
    - `G-WORD`: a glyph or alias contains `[A-Za-z]{3,}`.
    - `G-RESERVED`: contains a reserved punctuation char, or is exactly `X`, `Y` or `Z`, or is all digits.
    - `G-ROLE`: a role is missing or duplicated.
    - `G-LABEL`: no `en` label.
  - `Tok(type: str, value: str, col: int, symbol: Symbol | None = None)`. `col` is 1-based.
  - Token types: role names upper-cased for GRAMMAR_ROLES (`IMPLIES`, `COST_SEP`, …). Also `SYMBOL` (all other glossary symbols, including roles `self/loyalty/defense`), `NAME`, `EFFECT`, `MANA`, `NUMBER`, `VAR`, `LSQB`, `RSQB`, `LPAR`, `RPAR`, `COMMA`, `PLUS`, `MINUS`, `SLASH`, `DASH`.
  - `tokenize(text: str, g: Glossary) -> list[Tok]`, raises `TokenizeError(col: int, message: str)`.
  - `to_ascii(text: str, g: Glossary) -> str`: replaces each glossary token (including name/effect delimiters) with its ASCII alias. Whitespace between tokens is preserved by rebuilding from token spans.

Tokenizer algorithm (not determined by tests, so here it is). At each position, skip whitespace, then try in order:
1. NAME: name_open glyph or alias, then the shortest run up to the matching close (glyph ↔ glyph, alias ↔ alias), no newline. Value = inner key. Same for EFFECT.
2. MANA: `\{[^{}\s]+\}`.
3. NUMBER: `\d+`.
4. **Longest match** among all glossary glyphs/aliases and the fixed punctuation `[ ] ( ) , / + - —`.
5. VAR: `[XYZ]`, only when step 4 found nothing longer.

Otherwise raise `TokenizeError(col, "unknown symbol 'c'")`. When a run of `[A-Za-z]{3,}` starts at that position, raise `"natural-language word 'Flying' outside a name"` instead.

**Files:**

**Interfaces:**
- Consumes: `tokenize`, `Tok`, `TokenizeError`, `Glossary`.
- Produces:
  - `LineParser(g: Glossary)` with `parse_ability(text) -> lark.Tree` and `parse_type_line(text) -> lark.Tree`. Both raise `LineSyntaxError(col: int, message: str)` (wraps TokenizeError and Lark `UnexpectedInput`).
  - The tree's top rule for abilities is one of `statement | triggered | activated`, optionally under `chapter | threshold | mode` and `label`.
  - `AbilityLine(lineno: int, text: str, tree: Tree)`, `FaceDoc(name: str, mana: str, type_line: str, type_tree: Tree, stats: str | None, abilities: list[AbilityLine], header_lineno: int)`, `CardDoc(path: Path, set_code: str, slug: str, faces: list[FaceDoc])`.
  - `parse_card_file(path: Path, parser: LineParser) -> tuple[CardDoc | None, list[Issue]]`. Never raises on content errors. Issue codes: `C-HEADER` (bad name/mana line), `C-SYNTAX` (with line + col), `C-EMPTY`.

`grammar.lark` (Earley, `lexer` = a custom `lark.lexer.Lexer` subclass that yields `lark.Token`s from `tokenize`):

```
%declare IMPLIES COST_SEP LABEL_SEP MODE_BULLET THRESHOLD_SEP CHAPTER SYMBOL NAME EFFECT MANA NUMBER VAR LSQB RSQB LPAR RPAR COMMA PLUS MINUS SLASH DASH
ability: prefix? label? body
prefix: CHAPTER NUMBER (COMMA NUMBER)*   -> chapter
      | NUMBER PLUS THRESHOLD_SEP        -> threshold
      | MODE_BULLET                      -> mode
label: term+ LABEL_SEP
body: expr                               -> statement
    | expr IMPLIES expr                  -> triggered
    | expr COST_SEP expr                 -> activated
expr: (term | COMMA)+
term: SYMBOL | MANA | NUMBER | VAR | NAME | EFFECT | PLUS | MINUS | SLASH
    | LSQB (term | COMMA)* RSQB          -> filter
    | LPAR (term | COMMA)+ RPAR          -> group
type_line: tterm+ (DASH tterm+)?
tterm: SYMBOL | NAME
```

Lark options: `parser="earley"`, `start=["ability","type_line"]`, `ambiguity="resolve"`.

Card file format (per face; faces separated by a line that is exactly `//`):
1. Header line 1: `NAME MANA*`. It must tokenize to exactly one `NAME` followed only by `MANA` tokens.
2. Header line 2: type line (`parse_type_line`).
3. Optional line 3, the stats line, if it matches `^[0-9X*+-]+/[0-9X*+-]+$` or starts with the loyalty/defense glyph or alias followed by a number.
4. One blank line, then ability lines until `//` or EOF.

Comment lines (`#`) and trailing blank lines are ignored. Normalize `\r\n` → `\n` and strip trailing whitespace first. `set_code` and `slug` come from the path (`cards/<set>/<slug>.mtgl`).

**Interfaces:**
- Consumes: everything above.
- Produces:
  - `validate_all(root: Path) -> tuple[list[Issue], dict]`. Uses `root/glossary`, `root/cards`, `root/data`. Returns issues and stats `{"cards": int, "ability_lines": int, "named_effect_lines": int, "named_effect_rate": float}`.
  - Checks, each `-> list[Issue]`:
    - `G-*`: glossary self-check.
    - `C-*`: file parsing.
    - `V-NAME-UNKNOWN`: a `NAME` token is not in `names.yaml` and is not a snapshot card or face name.
    - `V-EFFECT-UNKNOWN`: an `EFFECT` key is not in `named_effects.yaml`.
    - `V-FACES`: face count ≠ Scryfall face count.
    - `V-CARDNAME`: header name ≠ face name.
    - `V-MANA`: header mana ≠ `mana_cost`.
    - `V-TYPE`: the type line rendered in English ≠ `type_line`. Rendering: each `tterm` → `label(…, "en")`, joined by single spaces, with `" — "` before the subtypes.
    - `V-STATS`: P/T must equal `f"{power}/{toughness}"`. Loyalty/defense must be the glyph + the number.
    - `V-ALIGN`: number of ability lines ≠ `len(oracle_lines(face))`. The message includes both counts.
    - `V-MISSING`: a snapshot card has no file.
    - `V-ORPHAN`: a file has no snapshot card.
    - `V-CONSISTENCY`: the same `normalize_for_consistency` Oracle line maps to more than one distinct notation. Notations are compared as sequences of `(token type, canonical value)`, where the canonical value is the Symbol's glyph for glossary tokens, so whitespace and glyph/ASCII choice are ignored. Reported once per Oracle line, listing the files.
    - `G-DEF`: a keyword `definition` fails to tokenize.
    - `V-EFFECT-RATE`: warning when named_effect_rate ≥ 0.05.
  - `sync_names(root: Path) -> int`: appends to `glossary/names.yaml` every missing card name, face name and subtype from the snapshot, with `en` label = key. Subtypes come from `split_subtypes` on the part after `—`. Classes are `card` and `subtype`. Returns the count added and never removes or reorders entries.
  - CLI `mtglang validate [--root .] [--set trk|fra] [--only-existing]`:
    - prints one `Issue` per line and a stats summary;
    - exits 1 if there are errors;
    - `--only-existing` suppresses `V-MISSING`, for use during batch translation.
  - CLI `mtglang sync-names`.
